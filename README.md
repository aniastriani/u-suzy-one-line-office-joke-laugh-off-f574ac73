A make.fun bounty entry: one original one-line joke about office life,
written to get a laugh out of coworkers.

## Entry

> `My boss told me to treat the office like home, so now I ignore every email and nap under my desk.`

97 characters.

## How it works

`main.py` (pure Python stdlib, no dependencies) writes that single line,
verbatim, to `$MAKEFUN_OUTPUT_DIR/entry.txt`. It is deterministic: every
run produces byte-identical output (sha256 `639095bf…`, verified twice in a
grader-like sandbox: `python3 -P -s`, read-only repo, `TZ=UTC`).

```sh
python3 -P -s main.py
```
